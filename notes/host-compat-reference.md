## What Exactlane Preflight can and cannot check

Deployed profile at commit `529d6b43`. Preflight checks a caller-supplied snapshot against caller-supplied requirements. It does not fetch the host, the MCP server, or a live `tools/list`. A passing report is not evidence that any host will keep the tool.

It can report, for protocol `2026-07-28` and transport `streamable-http`, at most 10 tools: a required tool name that is absent; a required input or output path the snapshot does not declare; a schema keyword outside that profile's allowlist; a protocol revision or transport the profile does not run. On profile 0.3 the allowlist is `$schema`, `type`, `properties`, `required`, `items`, `additionalProperties`, `title`, `description`, `default`, `examples`, plus the annotations `$comment`, `deprecated`, `format`, `readOnly`, `writeOnly`, and `x-mcp-header`. `type` has to be one of `string`, `number`, `integer`, `boolean`, `array`, `object`, `null`. A keyword such as `anyOf`, `allOf`, `oneOf`, `not`, `if`, `then`, `else`, `enum`, or `pattern` makes that schema check `UNSUPPORTED`. A `type` array such as `["null","string"]` does too, because `type` must be a single string. Dependents of an unsupported schema stay `NOT_RUN`. `FAIL`, `NOT_RUN`, and `UNSUPPORTED` are different results.

It cannot tell whether Claude Code will silently drop a schema, whether Mastra's Ajv will reject a `$schema` dialect (the profile allows `$schema` and does not ask which validator understands it), or whether Anthropic will return 400 because a schema is not draft 2020-12. `nullable`, `example`, and `examples` are outside the allowlist, so they make the schema check `UNSUPPORTED`. On profile 0.3, `readOnly: true` anywhere inside a caller-provided input makes that input check `UNSUPPORTED`, and `writeOnly: true` on a required output path makes that output check `UNSUPPORTED`. That means the profile will not vouch for the field. It is a different result from a host rejecting the tool list, and a schema with only those annotations can still be dropped or rejected by a host the profile never sees. It also cannot tell whether a tool name will 400 an LLM API, or whether a server-side projection will reject a call the OpenAPI schema allows. This note does not add checks for any of that.
